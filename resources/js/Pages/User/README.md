# User app (front-end)

Authenticated **patient** and **pharmacy owner** experiences live here:

| Folder | Role |
|--------|------|
| `User/Patient/` | Patient dashboard, medicines, orders, prescriptions, payments, receipts |
| `User/Pharmacy/` | Pharmacy dashboard, inventory, orders, analytics |
| `User/Auth/` | Login, register, password reset, email verification |
| `User/Profile/` | Account profile |

Inertia page names match paths, e.g. `User/Patient/Dashboard`, `User/Auth/Login`.

**Not here:** `Landing/` (marketing), `Admin/` (admin panel).
